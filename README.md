# 源氏物語 —— 読みながら、舞台に立つ

源氏物語の「桐壺」「若紫」を、**物語を読み進めながら、要所で 3D の舞台を自分で動かして読む**古文の学習ゲームです。
高校 2 年・古典探究（配当 15 時間ほど）の授業用に作りました。姉妹作は[鴻門の会](https://github.com/sakadosoutan-boop/-koumonnokai-)と[寝殿造り3D探訪](https://github.com/sakadosoutan-boop/-3D-)。

## 遊び方

- `index.html` をブラウザで開く（ビルド不要）。一枚にまとめた版は `dist/index.html`（オフラインでも開けます）。
- 表紙で帖を選び、「はじめから読む」か、目次から段を選びます。`#kiritsubo/k4` のように URL で段を直接開くこともできます。
- **桐壺**（全 7 段）：あなたは桐壺の更衣。帝に愛されるほど人のそしりが増し、心地が細っていく。
- **若紫**（全 7 段）：あなたは十八歳の光源氏。北山の小柴垣のもとで、一人の少女を見つける。
- 問いは 6 種類：解釈／**主語は誰か**／**敬意の方向**（誰から誰へ・尊敬か謙譲か丁寧か）／心情／決断／和歌。
  敬意の方向は、答えたあと舞台の人物の間に矢印で示します。
- **3D を自分で動かす場面**
  - 桐壺 第四段「渡殿を渡る」：桐壺から清涼殿まで歩く。清涼殿からいちばん遠い局に住むことが、何を意味するかを体で知る。
  - 若紫 第二段「垣間見」：小柴垣のすき間から僧坊をのぞき、尼君・女房・童べ・走ってくる少女を見つける。見つけると原文の描写が出る。
- **原文帳**：読んだ原文を綴じていきます。原文に、現代語訳・語注・品詞分解・敬語の層を重ねて読めます（縦書き／横書き）。
- **図鑑**：敬語・助動詞・助詞・重要古語・平安のしきたり・和歌の修辞（130 項目）。
- **授業モード**（初期設定）：全段を開けます。誤答で失敗せず、一度目はヒントで読み直し、二度目に正解と解説。読解率は一度目の答えで数えます。
  **挑戦モード**ではメーターが物語に効き、原文と違う「異聞の結末」に入ることがあります。
- 設定で **3D** と **絵巻（軽量）** を切り替えられます。WebGL が使えない端末では自動で絵巻になります。文字を大きく（投影向け）・ルビの表示なども設定できます。
- スマホの縦持ちで全部遊べます。記録はその端末のブラウザ（localStorage `genji:v1`）に保存されます。

## 授業で使う（15 時間の目安）

| 時 | 内容 | ゲーム |
|---|---|---|
| 1 | 導入：平安の後宮、女御と更衣 | 桐壺「序 入内」 |
| 2〜4 | 桐壺「いづれの御時にか」〜「私物に思ほしかしづきたまふ」 | 第一段〜第三段（教科書範囲） |
| 5〜6 | 御局は桐壺なり／限りとて | 第四段（渡殿を渡る）・第五段 |
| 7 | 桐壺のまとめ、藤壺へ | 終「光る君」＋ふり返りの問い |
| 8 | 若紫の導入：北山へ | 若紫「序」・第一段 |
| 9〜12 | 小柴垣のもと〜雀の子〜若草と露〜まもらるるなりけり | 第二段（垣間見）〜第五段（教科書範囲） |
| 13 | 紫のゆかり | 終 |
| 14〜15 | まとめ・書く活動 | 結末画面の「ふり返りの問い」 |

毎時の流れは「ゲームで場面をつかむ（10〜15 分）→ 本文を精読 → ゲームの問いで確かめる」を想定しています。

## 先生に確認していただきたいこと

- 原文は Wikisource の校訂本文（渋谷栄一校訂・大島本系）と照らして書き、表記を教科書で一般的な形に整えたものです。**お使いの教科書そのものとは照合していません。**
- 品詞分解・敬意の方向・図鑑の説明は、**授業で使う前に校閲が必要**です。立場の分かれる所と迷った所は `docs/KOUSHOU.md`（桐壺）・`docs/KOUSHOU-wakamurasaki.md`（若紫）の「要確認」に挙げてあります。
- 物語の地の文と台詞の多くは創作です。画面では、原文の引用と創作を書体と色で区別しています。

## 公開する

GitHub の **Settings → Pages** で Source を「GitHub Actions」にすると、`main` に push するたびに `.github/workflows/pages.yml` が公開します（`https://sakadosoutan-boop.github.io/genjimonogatari/`）。

## 開発

| コマンド | 内容 |
|---|---|
| `npm test` | 帖データの静的検証 → 進行・保存・学習機能の回帰テスト（jsdom） |
| `npm run test:browser` | 実ブラウザ（Chromium）で PC・スマホ縦・3D を確認 |
| `npm run build` | 一枚にまとめた `dist/index.html` を作る |

- 取り決め（データ形式・舞台 API）は `docs/CONTRACT.md`。**帖＝データ 1 ファイル**（`src/data/<帖>.js`）で、帖を足すときは `index.html` に 1 行足すだけにしてあります。
- 3D は Three.js（r128）で手続き生成。外部モデル・画像・CDN は使っていません。
