# 考証メモ —— 桐壺（`src/data/kiritsubo.js`）と共通の図鑑（`src/data/bunpo.js`）

文法（品詞分解・敬意の方向）と本文の形は、**先生の最終確認が前提**です。若紫は `docs/KOUSHOU-wakamurasaki.md`、3D の建築・装束は `docs/KOUSHOU-3D.md`。

## 1. 出典の確認方法

- 確認に使った本文：ja.wikisource.org「源氏物語 (渋谷栄一校訂)/桐壺」（大島本系の校訂本文）。`?action=raw` で取得したテキストと照らして原文帳 22 段（k01〜k22）を書いた。
- **新編日本古典文学全集そのもの・お使いの教科書そのものは参照できていません。** 漢字の当て方・句読点・かぎ括弧・ルビは、教科書で一般的な形に整えたものです。教科書と表記や語句が違う箇所は、教科書に合わせて `text` を直してください（品詞分解 `hinshi` をつけた段は、`text` を直すと `npm run verify` が食い違いを知らせます）。
- 機械的な照合：原文帳の本文から 6 字以上の仮名の連なり 168 か所を取り出し、取得テキストに同じ並びがあるかを調べた結果、147 か所が一致。残り 21 か所は、出典側がその途中に漢字を当てているため一致しなかったもの（例：「思ひあがり」／「思ひ上がり」）で、語の違いは見つかっていません。ただしこの方法では、漢字で書かれた語の異同は確かめられません。
- 終の段（k6）の物語の中の原文引用は、原文帳の `text` と一字ずつ一致することを機械的に確かめています。

## 2. 教科書の範囲

- `scope: '教科書'` は第一段〜第三段（「いづれの御時にか」〜「私物に思ほしかしづきたまふこと限りなし」）に対応する段につけています。
- 第四段（御局は桐壺なり）・第五段（限りとて）・終（野分・藤壺）は、採録する教科書としない教科書があります。違う場合は `scope` を直してください。

## 3. 文法・敬語の「要確認」

品詞分解（`hinshi`）と敬語（`keigo`）は、教科書範囲の段につけています。次の点は立場が分かれる・誤りやすい所なので、授業で使う前に確認してください。

1. **「いとやむごとなき際にはあらぬが」の「が」**：同格の格助詞として扱っています（「〜方で、」）。接続助詞（逆接）と教える教科書・参考書はほぼありませんが、設問の誤答に入れてあります。
2. **「はばからせたまはず」「出だし立てさせたまひて」など**：「せ／させ＋たまふ」を最高敬語（尊敬＋尊敬）としています。使役と読める箇所がないか確認してください。
3. **「思ひたまへながら」「思ひたまへましかば」**：下二段「たまふ」（謙譲）としています。
4. **「かごとも聞こえつべくなむ」**：敬意の方向を「母君 → 帝」としています（言葉を取り次ぐ命婦ではなく、歌の相手である帝）。
5. **「月影ばかりぞ…差し入りたる」「あやしきまでぞおぼえたまへる」**：係り結び（連体形）として扱っています。
6. **敬意の出どころ**：地の文は「語り手（作者）」、会話文・手紙・歌は「話し手・書き手」としています。画面では語り手を「語り手（作者）」と表示します。
7. 図鑑（130 項目）の用例は本文から引いていますが、活用表・接続の説明は一般的な学校文法に沿って書いたもので、一項目ずつの校閲はまだです。

## 4. 創作の方針

- 視点人物は桐壺の更衣。原文は更衣の内面をほとんど語らないため、地の文と台詞の多くは**創作**です。画面では、原文の引用（語り手の声・色と書体を変えて表示）と創作を区別しています。
- 更衣の死後（終の段）は、語り手の声をたよりに残された人々を見る形にしています。
- 「御おぼえ」「人のそしり」「心地」のメーターは、「恨みを負ふつもりにやありけむ、いとあつしくなりゆき」という原文の因果を体感させるための仕掛けで、原文にある数値ではありません。授業モードでは結末に影響しません。
- 異聞の結末（入内しない／里にこもる）は挑戦モードだけで、原文の筋を否定するのではなく「なぜ原文ではそうならないのか」を原文の言葉で説明する形にしています。
- 後宮のいじめ・病・死は、原文の語（「あやしきわざ」「まさなきこと」）の範囲で描き、具体的な描写を足していません。
