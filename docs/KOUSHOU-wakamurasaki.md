## 3. 文法・敬語の「要確認」

品詞分解（hinshi）は w04〜w17 の全語。句読点・かぎ括弧にも `h:'記号'` の要素を入れてある（検証器が「つなげた文が text に含まれること」を見るため）。画面では記号を隠す想定。

1. **w04「長きに」の「に」**：接続助詞（〜うえに・ので）とした。格助詞（原因）とする参考書もある。
2. **w04・w05「いたう」「こよなう」**：形容詞の連用形ウ音便とした。「いたう」を副詞とする立場もある。
3. **w06「べう」**：当然の「べし」とした（可能・推量とする説明もある。「似るはずもない／似ることもできない」）。
4. **w06「広げたるやうに」**：「たる」完了、「やうに」は比況の助動詞「やうなり」連用形とした。「やう（名詞）＋に（断定）」とする立場もある。
5. **w07「何事ぞや」**：「ぞ」係助詞（文末用法）、「や」間投助詞とした。「や」を係助詞（疑問）とする説もある。「腹立ちたまへるか」の「か」は係助詞の文末用法（終助詞とする本もある）。
6. **w07・w08「子なめり」「人なめり」**：「な」は断定「なり」連体形「なる」の撥音便無表記。
7. **w07「尼君の見上げたるに」の「に」**：格助詞（見上げている顔に）とした。
8. **w08「まかりぬる」**：謙譲語（丁重語的な用法）で、敬意は話し手の乳母→聞き手（尼君）とした。雀が主語なので扱いが分かれる。
9. **w08「とぞ人言ふめるは」**：「める」は連体形（準体法）で「ぞ」の結びは流れた、と見て「結び」と書いていない。
10. **w09「聞こゆるを」の「を」**：接続助詞（逆接）とした。「心憂く」は連用形で言いさし。
11. **w11「似たてまつれるが」の「が」**：格助詞（主格）とした。接続助詞と取る説もある。
12. **w11 の敬意の主体**：「きこゆる」「たてまつれ」は地の文として語り手→藤壺とした。源氏の心内語と見れば源氏→藤壺。設問では「誰を高めているか」だけを問うている。
13. **w11「思ふにも、涙ぞ落つる」に尊敬語が無いこと**：設問で「語り手が源氏と一体化して語る」と説明した。授業での扱いに合わせてください。
14. **w12「おはせむとすらむ」**：「おはせ」サ変未然、「む」意志（推量とも）、「らむ」現在推量・連体形（「いかで」と呼応）。
15. **w12「ただ今」**：名詞とした（副詞とも）。w15 も同じ。
16. **w13「うつぶしたるに」の「に」**：格助詞とした（接続助詞とも）。「消えむそらなき」の「そら」は「空」と「心地・余裕」の両義として注に書いた。
17. **w14「いかでか…らむ」**：疑問（反語に近い）と説明。「消えむ」の「む」は意志とした（推量とも）。「またゐたる大人」は乳母とは別の女房（`otona`）とした。乳母が戻ったと読む説もある。
18. **w15「ここにはべりながら」の「はべり」**：丁寧語（僧都→尼君）とした。謙譲語と取る立場もある。「まうでざりける」「おはしましける」の「ける」は詠嘆とした。
19. **w15「簾下ろしつ」の主語**：尼君（の側）とした。実際に下ろすのは女房とも読める。
20. **w16「見たてまつりたまはむや」**：「む」勧誘、「や」係助詞の文末用法（疑問）とした。
21. **w17「見るよ」**：「見る」終止形＋間投助詞とした。「何人ならむ」の「む」は連体形（疑問語との呼応）とした。
22. **敬意の対象に人物 id が無いもの**（仏・故姫君・兵部卿宮）は、`to` を省いて `note` に書いた。
23. **w03 の `from: 'koremitsu'`**：話し手は「御供なる人」で惟光と特定できない。id が無いため惟光で代表させた。

## 4. 解釈として書いた所（本文と区別してある）

- 尼君が孫に尊敬語を使う理由を「親王の娘という生まれだから」と説明した箇所（一般的な説明だが解釈）。
- 「すずろに悲し」に源氏自身の境遇を重ねる読み（設問の解説で「解釈」と明記）。
- w10「眉のわたりうちけぶり」を「眉を抜いていない生まれたままの眉」とする注。
- 「紫」の歌から「紫の上」「紫式部」の呼び名が出たという説明（「と言われる」と書いた）。
- 瘧病を「今のマラリアに近いもの」とする注（「と言われる」と書いた）。

## 5. 創作部分の方針

- 視点は光源氏（`pov:'genji'`、地の文は「あなた」）。原文そのままの引用は `gen` ノードと `src:'gen'` の台詞だけ。それ以外は現代語の創作で、**原文の筋に無い出来事は足していない**。
- 創作で足したもの：①「判断」の選択肢（供の人数、身を乗り出す、など。原文どおりの選択が一つある）②挑戦モードの異聞の結末 `w-ibun`（気配に気づかれて簾が下りる。結末文に「原文にない、ゲームの異聞」と明記）③惟光・聖の現代語の台詞（原文の内容の言い換え）。
- 異聞に入る条件：`kehai` が 5 以上（第二段で「供人をみな連れる」＋第三段で「身を乗り出す」を両方選んだときだけ）。**授業モードでこの `if` を無効にするかはエンジン側の判断**（データは分岐を書いているだけ）。
- 少女の描き方：原文の語（うつくし・らうたげ・いはけなし）の範囲にとどめ、源氏の関心は原文どおり「藤壺に似ているから目が離れない」「ねびゆかむさまゆかしき」「かの人の御代はりに」として書いた。性的な描写は無い。現代の読者の違和感は、僧都・尼君が断る場面（w19、「いと似げなきことを」）と、振り返りの問い 5・6 で扱えるようにした。
- 序の舞台 `sato` は、桐壺の「里の殿は…改め造らせたまふ」（のちの二条院）に当たるため流用した。
- 明石の入道の娘の噂は、原文一行（「さて、その女は」と、問ひたまふ）と要約だけ。
