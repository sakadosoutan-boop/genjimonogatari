# 考証メモ —— 3D の舞台（`src/js/stage3d-*.js`）

外部モデル・画像を使わず、すべて手続き生成です。絵巻（吹抜屋台・引目鉤鼻）の約束事で見せることを優先し、実寸の復元は目指していません。

## 簡略化している点

- **内裏の配置（`kokyu`）**：殿舎の位置関係（清涼殿の北に弘徽殿、東北の隅に淑景舎＝桐壺、その間に複数の殿舎）は平安宮内裏の復元図に沿わせていますが、大きさ・間数・渡殿の本数は簡略化しています。「桐壺から清涼殿へ行くには、ほかの殿舎のそばを通る」ことが一目で分かることを優先しました。
- **渡る道筋**：更衣が実際にどの廊を通ったかは原文に書かれていません。「あまたの御方々を過ぎさせたまひて」に合う一つの道筋を仮に置いたものです。
- **人物（高精細版・`stage3d-hd.js`）**：顔と手の網目は Blender Studio「Human Base Meshes v1.2.0」（CC0）。男の頭と手は姉妹作「鴻門の会」が整えたものを使い回し、女性・子どもの頭は `tools/build-heian-heads.py` が同じ素材の写実の女性から Blender で作り直したもの。装束・髪・冠・烏帽子・小道具はすべて手続きで作っています。
  - **女性・子どもの顔は「脚色」です**（先生の指示「平安人を完全再現する白塗りの方向ではなく脚色でいいので若い女性は可愛くして」による）。白粉・引眉・お歯黒といった平安の化粧は再現していません。
    写実の女性の頭を、目の開きを広げ、上まぶたで黒目の上を少し覆い、顔の下半分を短く、鼻と唇を小さく、頬をふっくら、あごを小さく丸くする変形で「写実寄りだが可愛い」顔にし、
    明るい自然な肌・頬のほのかな赤み・自然な紅・ふんわりした自然な眉・上のまつ毛の生え際・二重の線・澄んだ黒褐色の瞳（虹彩の模様とキャッチライト）を手続きの画像で塗っています。
    若い女性と少女はさらに様式化しています（目を大きく丸く・目尻を少し上げる、小さく細い鼻、山形のはっきりした小さな唇、口角を少し上げたやわらかな微笑み、短い中顔面と小さく丸いあご、ふっくらした頬、桃色寄りの明るい肌、上まぶたの太めのアイラインと目尻の小さな跳ね）。
    口角は、網目の唇の合わせ目（口の中の島と顔の島の境）ごと持ち上げています。少女は化粧の印象を出さず（紅・アイラインはごく淡く）、丸い顔・大きな目・小さな鼻と口・ほのかな微笑みの子どもらしい顔です。
  - 頭は 4 体：若い女性（桐壺の更衣・藤壺・弘徽殿の女御・女御更衣たち・女房）／大人の女性（母北の方・少納言の乳母・靫負命婦・北山の女房）／尼君／少女・子ども（若紫・犬君・童べ・一の皇子・若宮）。同じ頭から、顔の幅・目の大きさ・あごの長さを少しずつ変えて人を見分けさせます（藤壺は目をやや大きく、弘徽殿の女御は目をやや細くあごを長めに、など。性格づけの脚色）。
  - 尼君は「四十余ばかり……いと白うあてに痩せたれど、つらつきふくらかに」に合わせ、白い肌・ふっくらした頬に、ほうれい線・目尻と額の薄いしわで上品な年配の顔にしています。
  - 若紫などの子どもは、額を広く、目鼻を顔の下寄りに、頬をふっくら、あごを丸く、首を細くした子どもの顔です。化粧はせず、幼く清らかに。性的な印象を与える造形・強調はしていません。
  - 表情：若い女性と少女は、口を閉じたやわらかな微笑みをふだんの顔にしています（口角を上げて少し奥へ、頬の高いところを持ち上げ、下まぶたを少し上げた「笑った目」）。大人の女性は控えめな微笑み、尼君は穏やかな表情。
    泣く・伏す・礼・祈る・書く姿勢では、ゲームが表情なしの形へなめらかに戻します（`stage3d-hd-assets.js` の頭ごとの差 `dn` をモーフとして混ぜる）。
  - 髪：中央で分けた垂髪に、分け目から頬へかかる鬢削ぎの房（若い女性はあごの高さ、少女は頬まで）と、若い女性・大人の女性のこめかみの細い後れ毛。若紫の髪は肩で扇のように広がる。
  - 子どもの前髪（目刺し・めざし）：若紫・犬君・童べは、前髪を眉の高さで切りそろえています。平安の童の髪は、肩のあたりで切りそろえた振分髪に、額の髪を目のあたりまで垂らして切る「目刺し」で、
    『枕草子』「うつくしきもの」の「頭は尼そぎなるちごの、目に髪のおほへるを、かきはやらで、うちかたぶきて物など見たるも、うつくし」（髪が目にかかる幼子）がその姿を伝えます。ここでは顔が見えるよう、目にかからない眉の高さにしています（脚色）。
    房の帯には、縁と毛先が細い毛に分かれる透明度の画像を当て、頭頂には艶の輪を入れています。肌の画像の頭皮側は、ゲームの髪の殻と同じ生え際の式で髪色に塗り、殻の縁が透けても肌の帯に見えないようにしています。
  - 肌の材質には、影側が灰色・黄ばみに沈まないよう、やわらかな暖かい補助光と輪郭のほのかな透けを足しています（`stage3d-hd.js` の `skinMat`）。
  - 若い男（光源氏・惟光など直衣・狩衣の人）：張良の頭（`ryo`）。帝・上達部（束帯）：陳平の頭（`chin`）と口ひげ・あごひげ。僧都・聖：范増の老いた頭（`zo`）を剃髪で。
  - 髪：頭皮の形から作った髪の殻に、房を重ねた垂髪（額髪・鬢・背から裾の上へ流れて床に広がる）。尼君は肩で切りそろえた尼削ぎ、若紫は肩のあたりで扇を広げたように広がる髪、童は背の中ほどまで、幼子（若宮）は短い髪、一の皇子は角髪（みづら）。
  - 装束：袿の重ね（襟元・袖口・裾・前の合わせ目に、`chars.js` の `colors` の順で襲の色が段になって見える）と紅の長袴（若紫など童は袴を見せない。尼君は鈍色）。男は盤領の直衣・束帯（黒の袍・石帯・笏・下襲の裾）・狩衣（立烏帽子）。帝は御引直衣（白の直衣を後ろへ引き、紅の袴、冠の纓を立てる立纓）。僧は袈裟を左肩から斜めに。
  - 子どもは頭身を下げ（頭を大きめに、顔の下半分を短く）、若紫は十歳ほどの少女として幼く清らかに作っています。性的な印象を与える造形はしていません。
  - 文様・有職の細部（地紋の種類、色目の名、冠の細部）は省略・簡略化しています。檜扇は金地に霞と花の絵、色糸を垂らした形。
- **人物（簡素な人形・`stage3d-figures.js`）**：データが届くまで・画質 lite のときに使う引目鉤鼻の人形。装束は型と襲の色の重なりだけを表します。
- **舞台の質感**：木目・柾目・畳の目・御簾のひご・檜皮・やまと絵（金箔の地に緑青の山・群青の水と波・松・すやり霞）・几帳の帷（裾濃に朽木形）は Canvas で描いた手続きのテクスチャです。特定の作品の写しではありません。
- **北山の僧坊（`soubou`）**：小柴垣・西面の部屋・持仏・少し上げた簾という原文の要素を置いたもので、特定の寺の復元ではありません。垣間見では、垣の外から垣のすき間ごしに、垣の向こうの部屋（数間先）をのぞく構図にしています。距離は遊びやすさのために調整したもので、実寸ではありません。
- **季節・時刻**：光は 5 種（朝・昼・夕・夜・月夜）、季節は 4 種の色替えです。

## 要確認

- 殿舎の名前の札（登花殿・貞観殿など）の位置。
- 帝の装束（御引直衣・立纓）、尼君の姿（尼削ぎ）、若紫の「白き衣、山吹などのなえたる」の色。
- 高精細版で童に袴を見せていない点、女房装束を袿姿（唐衣・裳なし）にしている点。
- 女性の顔の化粧（白粉・引眉・お歯黒）を再現せず、現代的な「可愛さ」に脚色している点（授業で「実際の平安の化粧はどうだったか」を補うとよい）。
- 「目刺し」の語義と『枕草子』「うつくしきもの」の本文（記憶による引用。底本に当たって確かめる）。前髪を眉の高さにしている点（実際は目にかかるほど）。
- 3D の見え方は機種で違います。動作が重い端末では、設定で「絵巻（軽量）」に切り替えてください。
